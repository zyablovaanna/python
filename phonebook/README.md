 словаря. Ключом является кортеж «фамилия, имя, отчество». Предусмотреть
следующие возможности:
 – добавить контакт,
 
 – удалить контакт,

 – напечатать только все ФИО попавших в книгу жителей без номеров,
 
 – очистить телефонную книгу,
